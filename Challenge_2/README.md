# Challenge 2: Pipeline de Machine Learning

## Minería de Asteroides

**Curso:** Machine Learning  
**Universidad:** Universidad Peruana Cayetano Heredia  
**Docente:** Yannick Patrick Carrasco Merma

### Descripción

Este proyecto aborda la evaluación de estrategias de inversión en minería de asteroides mediante técnicas de Inteligencia Artificial y Machine Learning.

Se desarrollan dos pipelines:

- **Pipeline 1:** Razonamiento, espacio de estados, exploración, búsqueda y resultados.
- **Pipeline 2:** Predicción y visualización mediante modelos de regresión.

Además, se implementará una aplicación web responsive para visualizar e interactuar con los resultados.
